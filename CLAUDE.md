# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Is

Personal kitty terminal configuration (dotfiles). This is not a software
project — there is no build system, tests, or linting.

## Branches

- `main` — macOS config.
- `omarchy` — Linux/Omarchy config, ported from `main`. Use only on Omarchy
  (Arch Linux + Hyprland). Deployed to `~/.config/kitty/`.

This file describes the `omarchy` branch. See the README for the full list of
differences from `main`.

## Repository Structure

- `kitty.conf` — the entire configuration. The `omarchy` branch ships no
  bundled color schemes; colors come from Omarchy's generated theme file via
  `include ~/.local/state/omarchy/current/theme/kitty.conf`.
- `LICENSE` — license.

## Key Configuration Choices

- **Colors come from Omarchy.** The `include` at the top of `kitty.conf` points
  at `~/.local/state/omarchy/current/theme/kitty.conf`, regenerated by
  `omarchy theme set`. Never hard-code colors or add `set_colors` shortcuts —
  the terminal must always match the active OS theme.
- **`kitty_mod` is `ctrl+shift`** (kitty's default) because SUPER drives
  Hyprland. Splits are `ctrl+shift+l` (hsplit) and `ctrl+shift+j` (vsplit);
  moves are `ctrl+shift+alt+h/j/k/l` (not `kitty_mod+shift+...`, which would
  collapse onto `kitty_mod+...`).
- **Opacity/blur belong to the compositor.** `background_opacity 1.00`; do not
  add `background_blur` or `dynamic_background_opacity`. Omarchy controls
  opacity and blur with a Hyprland window rule.
- **`listen_on` must stay** `unix:${XDG_RUNTIME_DIR}/omarchy-kitty-{kitty_pid}`
  so Omarchy's cwd lookup works.
- **Font:** JuliaMono, with Nerd Font ranges mapped to JetBrainsMono Nerd Font.
- **No italics.** `italic_font` and `bold_italic_font` are pinned to the
  upright JuliaMono faces (Regular / SemiBold). Do not restore `auto`; italic
  text must render upright everywhere.

## When Editing

- Apply changes with `omarchy restart terminal`.
- Validate the config parses without unknown keys before committing.
- Do not reintroduce macOS-only options (`macos_*`, Cmd/Super maps, notch
  margins) or bundled themes on this branch.
